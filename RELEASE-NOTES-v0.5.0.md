# Perfo / Saver v0.5.0 (Beta)

First public beta for Dell + CATIA users.

## Included

- Compact two-button PERFO / SAVER window
- PERFO: Ultimate Performance + Dell Ultra Performance + Energy saver off
- SAVER: Power saver + Dell Quiet + Energy saver on
- Turkish and English instructions
- A separate non-elevated helper for the Windows Energy saver switch

## Before using

- Keep the two `.exe` files in the same folder.
- Confirm Dell Optimizer and both Windows power plans are installed.
- Approve the administrator prompt for the main application.

## Known limitation

This release is tested on one Dell configuration. Energy saver automation should be tested on other Windows 11 versions and Dell models. Please report compatibility results through GitHub Issues.
