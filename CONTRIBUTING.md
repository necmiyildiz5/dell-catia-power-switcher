# Contributing / Katkı

Thank you for helping test Perfo / Saver on Dell + CATIA systems.

## Report a problem

Open an issue with:

- Dell model
- Windows edition and version
- Dell Optimizer version
- Whether PERFO or SAVER failed
- The text of `son-islem.txt` (remove any personal paths first)

Do not post serial numbers, Windows product keys, or work files.

## Pull requests

Keep each pull request focused. Explain the Dell/Windows configuration used for testing and update the bilingual documentation if behavior changes.

---

Dell + CATIA sistemlerinde Perfo / Saver’ı test etmeye yardımcı olduğunuz için teşekkürler.

## Sorun bildirimi

Şunları içeren bir Issue açın:

- Dell modeli
- Windows sürümü
- Dell Optimizer sürümü
- PERFO mu SAVER mı hata verdi
- `son-islem.txt` içeriği (kişisel klasör yollarını önce silin)

Seri numarası, Windows ürün anahtarı veya iş dosyası paylaşmayın.

## Pull request

Her pull request tek bir konuya odaklansın. Denemeyi yaptığınız Dell/Windows kurulumunu yazın ve davranış değiştiyse iki dilli dokümantasyonu güncelleyin.
